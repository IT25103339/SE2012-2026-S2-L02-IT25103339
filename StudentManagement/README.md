# SE2012 - Java Programming Practical 2: Student Management System

A modular Java application built for the SE2012 Practical 2. This project demonstrates the use of Object-Oriented Programming (OOP) concepts, multiple packages, control structures, and array-based sorting and searching.

## Project Structure
- `models/` - Contains the `Student` and `Course` data models.
- `services/` - Contains the `EnrollmentManager` business logic.
- `mainapp/` - Contains the `Main` class with the interactive menu and array operations.

## Prerequisites
- Java Development Kit (JDK) 8 or higher installed and added to your system PATH.

## How to Compile
Open your terminal or command prompt in the root directory of the project (the folder containing the `models`, `services`, and `mainapp` folders) and run the following command:

```bash
javac models/*.java services/*.java mainapp/*.java
